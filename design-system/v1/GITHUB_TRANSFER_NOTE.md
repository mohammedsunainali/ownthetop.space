# GitHub Transfer Note — Design System V1

This branch contains the production design-system source, genuine vector assets, tokens, documentation, Figma handoff metadata, and the runnable static documentation website.

The complete locally verified package also contains generated PNG preview/export files and generated GLB world assets. Those binary artifacts were produced and verified during the build, but the current GitHub connector in this session does not support direct transfer of mounted binary files. They are therefore not represented as `READY` in Git merely because a filename was planned.

Canonical 3D mascot source/render artifacts remain remote-source indexed in `3d/mascot/REMOTE-SOURCE.json` and `3d/mascot/remote-production-renders.json`.

For binary handoff, use the downloadable ZIP packages generated in the build session, or copy the verified local binaries into the paths documented by `GITHUB_CHANGESET.md` with a normal Git client.

No screenshot/reference image has been promoted to a production asset.
