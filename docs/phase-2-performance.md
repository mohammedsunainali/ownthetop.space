# Phase 2 performance review

- Canvas DPR is capped at 1.75 desktop and 1.25 mobile; mobile disables shadows and reduces companion buildings, vegetation and visible aircraft. Reduced motion skips the intro climb and freezes decorative aircraft, traffic and pedestrian motion.
- Three production animation callbacks remain: camera interpolation/intro, one aircraft controller, and one traffic/pedestrian controller. Renderer diagnostics is development-only. There are no per-frame React state writes.
- Paid floors are instanced per tower: three wing instances plus front/side glazing and mullion instances per listing. Instance ID maps back to exactly one listing. The development-only `?stressFloors=220` fixture creates 220 deterministic company listings without mutating canonical 20/10/10 data.
- Facade CanvasTextures exist only for the leader or at most five focused nearby ranks, are cached by listing display state, and use an LRU cap of 24. No paid-floor DOM/`Html` overlays remain. The procedural crown's repeated glass and mullions are also instanced.
- Companion buildings, three vegetation families, vehicles, pedestrians and clouds use instancing. Day/sunset/night updates shared materials and lights without rebuilding geometry or changing rank order.
- WebGL capability is checked before mounting Canvas. `?fallback2d` exercises the same accessible 40-row fallback path; Canvas creation errors are handled by the world error boundary.
- `RendererDiagnostics` exposes two-second samples through `window.__OWNTHTOP_PERF__` and the canvas `data-ott-perf` attribute. A final 375×812 mobile-emulated Chrome sample reported **11 FPS, 134 draw calls, 34,760 triangles, 201 geometries, 10 textures**. A final 220-floor software-rendered headless Chrome sample reported **5 FPS, 263 draw calls, 151,350 triangles, 202 geometries, 10 textures**. Crown instancing reduced that stress sample from **487 to 263 draw calls** and **394 to 202 geometries**.
- Headless SwiftShader values are diagnostic load comparisons, not physical-device performance claims. Chrome DevTools MCP/Core Web Vitals tracing was unavailable. Physical-device sustained FPS, INP/LCP/CLS and long-session thermal behavior remain unverified, so performance cannot receive a PASS from these samples alone.
